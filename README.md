# 평화자료실 (Peace Archive for Korean Peninsula)

한반도 평화를 위한 카드뉴스·웹툰 자료실입니다.
시사 이슈를 시민 눈높이로 쉽게 풀어냅니다.

**공개 주소**: https://peace-archive.github.io/

## 구성

| 자료 | 경로 | 내용 |
|------|------|------|
| 자료실 홈 | `/` | 카드뉴스·웹툰 목록 |
| 웹툰 | `/webtoon/` | 「한국의 핵잠수함 도입, 무엇을 위한 걸까요?」 (아빠·딸 대화극, 15컷) |
| 카드뉴스 | `/cardnews/` | 「한국이 '핵잠수함'을 도입한다고요?」 (8장) |

## 특징

- 순수 정적 사이트 (HTML/CSS/JS) — GitHub Pages 호스팅

- 반응형 (모바일 최적화)
